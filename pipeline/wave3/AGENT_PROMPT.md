- PROMPT.md: قواعد المهمة بالتفصيل. اقراه كله الأول والتزم بيه حرفيًا.

## المطلوب
اشتغل على كل الباتشات بالترتيب ده: B كلها، بعدها C كلها، بعدها A كلها. ولكل باتش:

1. افتح الملف واقرا كل عنصر فيه، وكل مقطع (passage أو context) كامل بنفسك.
2. طلّع الرد حسب قواعد PROMPT.md للمهمة دي (A أو B أو C)، وبنفس شكل الـ JSON المكتوب هناك بالظبط.
3. احفظ الرد في `results/<اسم الباتش>.json`، زي `results/B_01.json`.
4. شغّل كود التحقق اللي تحت على الملف ده، واحذف أي نص يفشل.
5. سجّل في `results/progress.txt` سطر فيه: اسم الباتش، وعدد اللي اتحفظ، وعدد اللي اتحذف.
6. كمّل على الباتش اللي بعده من غير ما تستنى رد مني.

## ممنوع تمامًا
- **الاستخراج الآلي:** ممنوع تطلّع المقتطفات بكود أو regex أو بالبحث عن كلمات زي "أي" و"يعني". الاختيار لازم يكون بقرايتك وفهمك لكل مقطع. الكود مسموح بيه بس لفتح الملفات وحفظها وللتحقق.
- **إعادة الصياغة:** ممنوع تعيد صياغة أي نص. أي نص في الرد لازم يكون منسوخ حرفيًا من المقطع.
- **تعدية العناصر:** ممنوع تعدّي عناصر من غير ما تقراها، أو تختصر الشغل عشان تخلص أسرع. لو العنصر ملهوش حاجة سيبه، بس بعد ما تقراه.

## ضمان الجودة (إلزامي)
- **قرايتك في رسالتك:** افتح الملف بكود عادي، وبعدين اطبع العناصر 10 عناصر في المرة، واقراهم في رسالتك قبل ما تقرر. متكتبش رد عنصر ما اتعرضش عليك نصه.
- **سجل قرار لكل عنصر:** لكل عنصر اكتب في `results/<اسم الباتش>_log.txt` سطر واحد بالشكل ده:
  `سورة:آية إمام | أخذت/سبت | السبب في كلمات`
  مثال: `2:255 IT | سبت | استشهاد ضمن سرد آيات بدون شرح`.
  والسبب لازم يكون خاص بالعنصر ده، مش عبارة واحدة متكررة.
- **مراجعة ذاتية بعد كل باتش:** اختار 3 عناصر عشوائية من اللي أخدتها، وارجع لنصها، واتأكد إن المقتطف كلام الإمام نفسه، وإنه بيشرح الآية دي برقمها. لو لقيت غلط صلّحه، واكتب ده في السجل.
- **مهمة واحدة في الوقت:** باتش واحد في الوقت. متعملش سكريبت يلف على كل الباتشات، ومتوزعش الشغل على أدوات أو نماذج تانية.
- **متستعجلش:** لو حسيت إنك بتستعجل أو السياق بقى طويل، وقّف وقولّي، ومتكملش بجودة أقل. الدقة أهم من السرعة. ومش مطلوب تخلص في جلسة واحدة.

## كود التحقق (شغّله بعد كل باتش)
```python
import json, re, sys
ws = lambda s: re.sub(r'\s+', ' ', s).strip()

def verify(batch_path, result_path):
    B = json.load(open(batch_path, encoding='utf-8'))
    R = json.load(open(result_path, encoding='utf-8'))
    bad = 0
    if B['task'] in ('A', 'B'):
        pool = {}
        for it in B['items']:
            for p in it['passages']:
                pool.setdefault((it['imam'], p['w']), []).append(ws(p['text']))
        ok = lambda a, w, t: any(ws(t) in s for s in pool.get((a, w), []))
        for su, x in R.items():
            for a, vs in x.get('summ', {}).items():
                for v in list(vs):
                    keep = [e for e in vs[v] if ok(a, e[0], e[1])]
                    bad += len(vs[v]) - len(keep)
                    vs[v] = keep
            for a, vs in x.get('nuq', {}).items():
                for v in list(vs):
                    keep = []
                    for e in vs[v]:
                        if not ok(a, e['w'], e['t']):
                            bad += 1
                            continue
                        if e.get('rt') and not ok(a, e['w'], e['rt']):
                            e.pop('rt')
                        keep.append(e)
                    vs[v] = keep
    else:
        ctx = {it['id']: ws(it['context']) for it in B['items']}
        keep = []
        for f in R.get('fix', []):
            if f['id'] not in ctx:
                bad += 1
                continue
            if f.get('rt') and ws(f['rt']) not in ctx[f['id']]:
                f.pop('rt')
            keep.append(f)
        R['fix'] = keep
    json.dump(R, open(result_path, 'w', encoding='utf-8'), ensure_ascii=False, indent=1)
    return bad
```
