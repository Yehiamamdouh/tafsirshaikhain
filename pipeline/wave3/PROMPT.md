# مهمة: خدمة تفسير ابن تيمية وابن القيم

الملف المرفق JSON، وفيه حقل `task` قيمته **A** أو **B** أو **C**. نفّذ المهمة اللي تخص الحرف ده بس.

## القواعد العامة (لكل المهام)
1. **النص بحروفه.** أي نص تكتبه في الرد لازم يكون منسوخ حرف بحرف من نص المقاطع: نفس الهمزات وعلامات الترقيم والأقواس. ممنوع تعيد الصياغة أو تصحح أو تضيف أي كلمة. أي نص مش موجود بالحرف هيترفض آليًا.
2. **كلام الإمام نفسه بس.** متاخدش كلام خصم بيحكيه الإمام: لا فقرة بتبدأ بـ"قالوا" أو "فإن قيل" أو "احتجوا" أو "زعموا"، ولا حجج الطرف التاني في مناظرة، ولا كلام ابن عربي أو الفلاسفة أو المتكلمين اللي الإمام بينقله عشان يرد عليه.
3. **أقوال الصحابة والتابعين والمفسرين** اللي الإمام بينقلها (زي "قال ابن عباس" أو "قال مجاهد" أو "قال أبو عبيدة") مكانها `nuq` مش `summ`. وكلام الإمام نفسه مكانه `summ`، حتى لو بيقول "فبين الله" أو "أي كذا".
4. **مش شرح، فمتاخدهوش:**
   - جملة بتقدّم الآية بس.
   - كلام عن مصادر التفسير أو عن الكتب.
   - تنزيل الآية على خصوم الإمام في عصره.
   - مسألة فقهية بعيدة عن معنى الآية.
5. **الآية برقمها:** اتأكد إن الشرح فعلًا عن الآية دي برقمها، مش عن آية تانية جت في نفس الفقرة.
6. **علامات التنصيص:** لو في `"` جوه نص منقول، اكتبها `\"`.
7. **الرد:** ردّ بـ JSON بس، جوه code block واحد، من غير أي كلام قبله أو بعده. لو مفيش حاجة خالص ردّ بـ `{}`.

## مهمة A: استخراج مختصر لآيات معندهاش مختصر
كل عنصر فيه آية (`surah` و`ayah` و`ayah_text`)، والإمام (`imam`: IT = ابن تيمية، IQ = ابن القيم)، ومقاطع من كتبه في `passages`. كل مقطع فيه `w` (كود الكتاب) و`ref` و`text`.

- دوّر على كلام الإمام اللي بيشرح معنى الآية دي تحديدًا: تفسير لفظ، أو بيان المراد، أو "أي" و"يعني"، أو "فأخبر أن" و"فدل على"، أو ترجيح بين الأقوال.
- المقتطف من جملة لـ3 جمل، وحوالي 300 حرف بالكتير. تقدر تحط لحد 3 مقتطفات للآية الواحدة.
- **لو الآية مذكورة كاستشهاد بس، سيبها خالص ومتكتبهاش.** أغلب العناصر في المهمة دي هتكون كده، وده طبيعي. متطلعش حاجة ضعيفة عشان تملا الرد.
- مقاطع كتاب `IjtimacJuyush` أغلبها نقول عن السلف والأئمة، فدي مكانها `nuq` غالبًا.

## مهمة B: تكملة مختصر قصير
كل عنصر فيه:
- `existing`: المقتطفات الموجودة للآية دلوقتي، وهي قصيرة.
- `passages`: مقاطع أوسع من كتب الإمام.

- زوّد **أهم نقطة أو نقطتين في معنى الآية** مش موجودين في `existing`، من كلام الإمام وبالحرف.
- متكررش اللي في `existing`، ومتجيبش جملة أطول بتحتويه.
- لو `existing` كفاية أو المقاطع مفيهاش زيادة حقيقية، سيب الآية.
- لو لقيت أقوال للسلف أوردها الإمام في الآية، حطها في `nuq`.

### شكل الرد لمهمتي A وB
```json
{
  "53": {
    "summ": { "IT": { "22": [["MajmucFatawa", "النص بالحرف"]] } },
    "nuq":  { "IQ": { "13": [ { "w": "MadarijSalikin", "who": "ابن عباس", "st": "حكاه", "t": "نص القول بالحرف", "rt": "جملة رد الإمام أو ترجيحه بالحرف (اختياري)" } ] } }
  }
}
```
- المفاتيح الأولى أرقام السور، وجواها أرقام الآيات، والاتنين نصوص (strings).
- `w` هو كود الكتاب، ويتنسخ من المقطع زي ما هو بالظبط.
- `st` (موقف الإمام من القول) لازم يكون واحدة بس من دول:
  - `حكاه`: نقله من غير حكم
  - `أقرّه`: وافقه أو اعتمده
  - `ردّه`: رفضه أو غلّطه
  - `استشهد به`: حديث أو أثر جابه دليل
  - `رجّح غيره`: ذكره ورجّح قول تاني
- `rt` اختياري، ويتحط لما يكون الموقف `ردّه` أو `رجّح غيره`.

## مهمة C: مراجعة موقف الإمام من قول نقله
كل عنصر فيه:
- `id`
- `who` و`t`: القول المنقول وصاحبه
- `current_st`: الموقف المكتوب حاليًا
- `current_rt`: جملة الرد أو الترجيح الحالية، لو موجودة
- `context`: السياق من كلام الإمام

اقرا السياق، وحدد موقف الإمام الحقيقي من القول. الموقف واحد من الخمسة اللي فوق.

- لو الموقف الحالي صح والـ `rt` سليم، **متكتبش العنصر**.
- لو محتاج تعديل، اكتبه.
- لو اكتشفت إن `t` مش قول منقول أصلًا، وإنه كلام الإمام نفسه، اكتب `"st": "كلام الإمام"`.
- ولو اكتشفت إن القول لخصم مش من السلف أو المفسرين، الموقف غالبًا `ردّه`، فاكتبه مع `rt`.

### شكل الرد لمهمة C
```json
{ "fix": [ { "id": "2|IT|62|0", "st": "ردّه", "rt": "جملة الرد من السياق بالحرف" } ] }
```
- `rt` اختياري، ولازم يكون منسوخ بالحرف من `context`.
- لو كله سليم ردّ بـ `{ "fix": [] }`.
