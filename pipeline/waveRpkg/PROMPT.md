## المواقف المسموحة
- `حكاه`: نقله من غير حكم
- `أقرّه`: وافقه أو اعتمده صراحة
- `ردّه`: رفضه أو غلّطه
- `استشهد به`: حديث أو أثر جابه دليل لكلامه
- `رجّح غيره`: ذكره ورجّح قول تاني
- `كلام الإمام`: النص أصلًا كلام الإمام نفسه مش منقول

## مهمة S: موقف الإمام من قول نقله (قرار مستقل)
كل عنصر فيه `who` و`t` (القول المنقول)، و`current_st`، و`context` (كلام الإمام حوالين النقل).
اقرا السياق كله واحكم بنفسك. **اكتب قرارك لكل العناصر من غير استثناء**، حتى لو موافق على `current_st`.
تنبيهات مهمة:
- لو الجملة بتحكي أكتر من قول مختلف ("منهم من قال… ومنهم من قال…") يبقى `حكاه`، مش `أقرّه`.
- `أقرّه` محتاج دليل واضح في السياق إن الإمام موافق (زي "وهو الصحيح"، "وهذا حق"، أو بنى عليه كلامه). مجرد النقل من غير تعليق = `حكاه`.
- `ردّه` لما الإمام يغلّط القول أو ينتقده، حتى لو بعدها بكام سطر.
- لو `ردّه` أو `رجّح غيره` اكتب `rt`: جملة الرد أو الترجيح من `context` بالحرف.
```json
{ "st": [ { "id": "2|IT|62|0", "st": "ردّه", "rt": "جملة من السياق بالحرف", "why": "سبب قصير" } ] }
```

## مهمة V: هل النص تحت الآية الصح؟
كل عنصر فيه `ayah` و`verse` (نص الآية) و`t` (النص المعروض تحت الآية دي) و`context_before`/`context_after`.
السؤال: هل `t` فعلًا كلام الإمام في معنى **الآية دي برقمها**؟
- لو أيوه: متكتبش العنصر.
- لو بيشرح آية تانية واضحة (اسمها أو نصها موجود في السياق): `"verdict": "move"` و`"to": "سورة:آية"` بالأرقام.
- لو مش شرح لأي آية (كلام عام أو فقه بعيد): `"verdict": "drop"`.
- لو مش متأكد: متكتبش العنصر.
```json
{ "verse": [ { "id": "23|IQ|4|0", "verdict": "move", "to": "23:99", "why": "سبب قصير" } ] }
```

## مهمة K: اكتمال النص
كل عنصر فيه `t` والسياق قبله (`context_before`) وبعده (`context_after`).
السؤال: هل `t` بيبدأ من نص الكلام (زي "هذا" أو "فإنه" ومش واضح بيرجع على إيه) أو بيقف قبل ما المعنى يكمل؟
- لو مفهوم لوحده: متكتبش العنصر.
- لو ناقص: اكتب `t` جديد = نفس النص القديم كامل، ومعاه أقل قدر من الكلام اللي قبله أو بعده يخلّي المعنى يكمل. **منسوخ بالحرف ومتصل** من `context_before + t + context_after`، ومتزودش أكتر من جملة أو اتنين.
- ممنوع تزود كلام خصم أو كلام عن آية تانية.
```json
{ "extend": [ { "id": "2|IT|17|1", "t": "النص الجديد كامل بالحرف" } ] }
```

## مهمة W: مين قايل الكلام؟
كل عنصر نص معروض على إنه **كلام الإمام نفسه**، وفيه كلمة زي "قال" أو "قيل" أو "ذكر".
السؤال: هل ده فعلًا كلام الإمام، ولا هو بينقل كلام حد تاني؟
- لو كلام الإمام (حتى لو بيقول "قال تعالى" أو "ثم ذكر" عن الآية): متكتبش العنصر.
- لو كله نقل عن صحابي أو تابعي أو مفسر: `"verdict": "move_nuq"` مع `who` (اسم القائل من النص) و`st` (موقف الإمام منه).
- لو كلام خصم أو كلام الإمام بيحكيه عشان يرد عليه: `"verdict": "drop"`.
- لو جزء منه كلام الإمام وجزء نقل: `"verdict": "trim"` و`t` = جزء كلام الإمام بس، منسوخ بالحرف من النص القديم.
```json
{ "who": [ { "id": "5|IT|3|0", "verdict": "move_nuq", "who": "مجاهد", "st": "أقرّه", "why": "سبب قصير" } ] }
```
