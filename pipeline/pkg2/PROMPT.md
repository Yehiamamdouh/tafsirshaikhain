# مهمة: استخراج مختصر معاني الآيات من كلام ابن تيمية وابن القيم

هبعتلك ملف JSON (batch_XX.json). كل عنصر فيه آية واحدة، ومعاها:
- `surah` و`ayah`: رقم السورة ورقم الآية
- `ayah_text`: نص الآية
- `imam`: يا IT (ابن تيمية) يا IQ (ابن القيم)
- `passages`: لحد 3 مقاطع من كتب الإمام ده بتذكر الآية. كل مقطع فيه `w` (كود الكتاب) و`ref` (الجزء/الصفحة) و`text`

## المطلوب
لكل آية، دوّر في المقاطع على كلام الإمام اللي بيشرح معنى الآية دي تحديدًا: تفسير لفظ، أو بيان المراد، أو "أي كذا"، أو "يعني"، أو "فأخبر أن"، أو "فدل على"، أو "والمراد"، أو ترجيح بين الأقوال.

### القواعد (مهمة جدًا)
1. **النص بحروفه.** انسخ الجملة من `text` حرف بحرف، بنفس الهمزات والتشكيل وعلامات الترقيم والأقواس. ممنوع تعيد الصياغة أو تصحح أو تختصر من النص أو تضيف أي كلمة. أي نص مش موجود بالحرف هيترفض آليًا.
2. **الطول:** من جملة واحدة لـ3 جمل، وبحد أقصى حوالي 300 حرف للمقتطف الواحد. لو في أكتر من فكرة مهمة، اعمل لحد مقتطفين أو 3 للآية.
3. **لو الآية مذكورة كاستشهاد بس** (ضمن سرد آيات، أو دليل على مسألة من غير ما يشرح معناها)، **سيبها خالص ومتطلعش ليها حاجة**. ده أحسن من مقتطف ضعيف.
4. **كلام الإمام نفسه بس.** متاخدش كلام حد تاني بيحكيه الإمام: لا كلام خصم، ولا فقرة بتبدأ بـ"قالوا" أو "فإن قيل" أو "احتجوا" أو "زعموا"، ولا كلام ابن عربي أو الفلاسفة أو المتكلمين اللي الإمام بينقله عشان يرد عليه.
5. **أقوال الصحابة والتابعين والمفسرين** اللي الإمام بينقلها، زي "قال ابن عباس" أو "قال مجاهد" أو "قال أبو عبيدة"، متتحطش في المختصر. دي بتتحط في **النقول** (`nuq`) زي ما تحت، مع موقف الإمام منها.
6. اتأكد إن الشرح فعلًا عن **الآية دي برقمها**، مش عن آية تانية جت في نفس الفقرة.
7. **مش شرح، فمتاخدهوش:**
   - جملة بتقدّم الآية بس، زي `وقال في " الإرادة الدينية ":`.
   - كلام عن مصادر التفسير أو عن الكتب.
   - تنزيل الآية على خصوم الإمام في عصره.
8. **كلام الإمام نفسه مكانه `summ` مش `nuq`.** حتى لو بيقول "فبين الله..." أو "أي على الحق...". النقول (`nuq`) بس لقول منسوب صراحة لشخص أو جماعة، زي "قال ابن عباس" أو "قال طائفة".
9. **علامات التنصيص جوه النص:** لو في `"` جوه نص منقول، اكتبها `\"` عشان الـ JSON ميبوظش.

## شكل الرد
ردّ بـ JSON بس، من غير أي كلام قبله أو بعده، بالشكل ده بالظبط:

```json
{
  "53": {
    "summ": {
      "IT": { "22": [["MajmucFatawa", "النص المنسوخ حرفيا"]] },
      "IQ": { "11": [["MadarijSalikin", "النص المنسوخ حرفيا"]] }
    },
    "nuq": {
      "IT": { "13": [ { "w": "FatawaKubra", "who": "ابن عباس", "st": "حكاه", "t": "نص القول المنقول حرفيا" } ] }
    }
  }
}
```

- المفاتيح الأولى أرقام السور (string)، وجواها أرقام الآيات (string).
- `summ`: كل عنصر فيه `[كود الكتاب w من المقطع, النص حرفيًا]`.
- `nuq`: كل عنصر فيه:
  - `w`: كود الكتاب
  - `who`: صاحب القول، زي "ابن عباس" أو "مجاهد" أو "أكثر المفسرين" أو "قيل"
  - `t`: نص القول حرفيًا
  - `st`: موقف الإمام، واحدة بس من دول:
    - `حكاه`: نقله من غير حكم
    - `أقرّه`: وافقه أو اعتمده
    - `ردّه`: رفضه أو غلّطه
    - `استشهد به`: حديث أو أثر جابه دليل
    - `رجّح غيره`: ذكره ورجّح قول تاني
  - `rt` (اختياري): لو `ردّه` أو `رجّح غيره`، حط جملة الرد أو الترجيح من كلام الإمام حرفيًا.
- كود الكتاب `w` يتنسخ زي ما هو في المقطع بالظبط.
- الآية اللي ملهاش حاجة متكتبهاش.
- لو الملف كله مفيهوش ولا آية فيها شرح، ردّ بـ `{}`.
